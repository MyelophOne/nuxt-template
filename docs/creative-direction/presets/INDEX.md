# On-demand visual style presets

Read only when the user names a style, asks to choose among styles, or accepts a specific proposed direction. These are local design instructions, not installed skills, runtime themes or code generators. A generic request for a beautiful/modern/premium site does not select a preset. New/open art direction still follows the brief; do not read all six files to begin every project.

## Common contract

- User requirements and established brand/layout win. Presets do not supersede AGENTS.md or installed layer contracts. A style name alone does not authorize new fonts/dependencies, 3D, a single theme, custom cursors, scroll hijacking or another primitive implementation.
- **System fonts remain the default.** Editorial roles may use Georgia with serif fallbacks; modern sans uses the inherited stack. Instrument Serif, Space Grotesk, Inter or Plus Jakarta Sans mentioned in inspiration examples are not automatic downloads. Explicitly requested fonts use the existing pipeline, actual glyph/weight coverage and safe fallbacks.
- Choose palette separately; use semantic roles and centralized replaceable colors. Preset colors are optional examples, not a mandatory palette or ban on other brand colors. No default milky haze, fluorescent grounds, mesh blobs or compulsory warm/cool bias in every neutral.
- Use package Grid and actual UI/media/icon/sticky/theme/i18n/reveal APIs. Expression comes from content, proportion, supported presentation and crops; never copy source CSS containers/buttons/reveal engines into the application.
- Establish a small material vocabulary: surface levels, shape roles, dividers/shadows and motion timings. A badge, portrait, field and preview need not share one radius; vary by role, not randomly per item. Adjacent sections may share a ground when the story benefits.
- Each useful section has a dominant visitor question; add a next action where needed, not a CTA quota. Retain substantial readable detail. Connect overview and detail through the subject, composition or spacing, not mandatory color alternation, blank breathing screens or fabricated quotes/stats.
- Choose one bounded expressive gesture with quieter support. Similar interactions share timing/easing. The composition must work before hydration, without JS, on touch and with reduced motion. Transform/opacity are often efficient, not a guarantee of compositor-only rendering or 60fps; measure actual cost.
- Full-width large hero media, immediate LCP, no default hero slider and no unsolicited 3D remain binding. Include the existing theme switch unless explicitly restricted. A dark-first style needs a deliberately designed light counterpart.

## Acceptance

Inspect a representative wide/narrow slice before repeating a preset. It must be recognizable through subject, type and composition without its label, motion or added glow. Compare entry, one lower section and main action: sustain the idea with varied rhythm. If changing colors/names makes it interchangeable with another generated site, revisit content and composition. Existing build/generate, SSR/hydration, responsive and task checks still apply; no award, conversion or performance guarantees.
