# Gallery Minimal

Trigger: explicit quiet-gallery/collection/minimal-portfolio direction. The work/object supplies identity; minimalism does not excuse empty content or tiny gray text. Apply the common contract in INDEX.md.

## Visual grammar

- Present actual works at useful scale with discreet readable labels and a clear browse/detail path. A collection may start directly with its listing. Large opening media, when present, follows the full-width rule.
- Establish calm alignment, confident type proportions and purposeful whitespace. Use inherited system type or a deliberate Georgia editorial role unless custom type is established. Avoid display headings competing with every work.
- Let actual aspect ratios or major/minor pairings create Grid rhythm. Preserve uncropped artwork when accuracy matters; identify detail crops and provide a complete-work path where applicable. Do not invent masonry or shuffle DOM order for appearance.
- Surfaces can be clear white, dark or brand-colored according to the brief. No automatic ivory ground, frosted veil, beige tint, border on every item or compulsory shadow. Required boundaries/focus stay visible.
- Cards are useful when they group image/title/detail; open figures/lists may work better where boxes add no value. Linked previews have restrained image/focus feedback; touch retains metadata.
- Keep enough prose to explain authorship, process, availability or actual specifications. Quiet presentation still supplies the information needed to decide.

## Prompt example

> Use Gallery Minimal: large, real-life works, a precise grid, precise typography, and legible captions. Clean surfaces without haze; minimal design, complete content, and functional navigation.

## Check

Work dominates without sacrificing finding/reading/acting. Inspect fidelity, caption contrast, mobile gaps, comparable item alignment and focus/contact visibility. Empty acres must not replace useful information.
