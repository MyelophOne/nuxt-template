# Graphic Playful

Trigger: explicit expressive/playful/bold-graphic direction. Useful for creative tools and cultural/consumer brands; not a reason to trivialize serious financial/legal decisions. Apply the common contract in INDEX.md.

## Visual grammar

- Choose one subject-related mechanism: a crop/frame relationship, geometric motif or contrasting type arrangement. Do not scatter unrelated stickers, arrows, emojis and squiggles around generic copy.
- Use strong controlled color blocks from a harmonious replaceable palette. A vivid accent need not dominate every surface. Preserve clear ink and comfortable supporting contrast; no compulsory neon or pastel haze.
- Pair a prominent typographic gesture with quiet readable explanation and actual imagery/output. Use available system weights and language coverage; personality does not require a novelty font download.
- Keep a coherent shape vocabulary; occasional sharp/rounded contrast can distinguish roles. Avoid random radii/cartoon controls. Existing buttons retain readable geometry and clear hierarchy.
- Let asymmetric Grid layouts or useful top offsets provide rhythm on desktop. Mobile retains the motif through crop/color/order, not a tiny scaled-down scene or essential controls overlapped by graphics.
- Optional bounded hover/press feedback uses existing reveal and owned CSS. No default sound, confetti dependency, permanent bounce, custom cursor or magnetic moving target.

## Prompt example

> Use Graphic Playful: expressive composition, a single recognizable graphic motif, and harmonious color planes. Maintain legibility and ease of use; avoid random embellishments and acidic backgrounds.

## Check

Temporarily remove decoration: offer, task and hierarchy should remain clear. Restore only meaningful identity. Verify both themes, long copy, keyboard/touch and reduced motion; playful controls remain conventional to operate.
