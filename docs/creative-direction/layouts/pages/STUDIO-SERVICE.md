# Studio / portfolio / professional service

Read for work quality, expertise or a service decision. No SaaS dashboard/code editor or invented client history as a substitute for the subject.

- **Work-led studio:** identity/offer → substantial work scene → complementary work → services/approach → process/fit → useful decision support → real next step. Captions explain actual context/contribution.
- **Service detail:** audience/problem and deliverable → concrete output/example → scope/boundaries → method → decision questions → requested action. Distinguish included work from what requires agreement.
- **Portfolio collection:** useful work early, meaningful context/categories, real filters only where warranted. A detail page follows the project through relevant images and explanation.

A dominant Grid column and smaller companion (e.g. a 7/5 relationship) can express priority. Different aspect ratios/top offsets serve the content, not random asymmetry; clear offsets on phones. Existing sticky compositions can keep a short summary beside a longer process/FAQ, never pin the whole story.

Large image-led heroes span the viewport. Respect focal areas, use UiCard for meaningful service/project units and open lists where they better explain a method. Relevant previews get restrained hover without fake click affordances. Clearly label concepts/speculative work.

Mobile gets an authored crop/order, readable captions and the same core scope information; don't hide evidence or turn every paragraph into a card. Use verified Grid/media/card/sticky/disclosure/ready-page contracts, preserving root depth/SEO requirements.

Verify specialty, inspectable meaningful work, understandable scope and an honest working action. If only the name could change for any agency, revise subject/content/composition.
