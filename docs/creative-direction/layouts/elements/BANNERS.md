# Banners and campaign creatives

Read for an actual promotion/announcement or requested creative export. A website hero also follows HERO-FEATURES and the root full-width large-image rule; a consent banner belongs to the existing consent subsystem. Do not add banners by decoration quota.

Clarify only missing purpose, placement/format, message, real destination, brand/assets and required variants. A web banner is responsive content; a social/ad export has exact requested dimensions and platform crop/overlay zones. Verify current platform specifications when exporting, rather than treating a source's dimension table, text-percentage rule or print settings as universal policy. Don't force three concepts or an approval stop when one result is authorized.

Compose one main message, relevant visual and one dominant action when needed. Keep supporting conditions legible, subordinate and truthful. Choose a focal subject and purposeful negative space for text; safe zones follow actual crop/placement, not an automatic central 70–80% rule or bottom-right CTA. A narrow strip often needs shorter approved wording or stacked flow, not scaled-down desktop art.

On the website keep headline, conditions and action as semantic selectable HTML, reusing Grid, UiHeading, UiButton, media and existing dismissal behavior where available. Don't bake operational text/buttons into an image or imply a static exported CTA is an interactive control. Generated artwork, if needed, should leave copy editable; no crude CSS/SVG substitute for essential photography. User palette/system fonts and explicit-only 3D animation still apply; neon/glass/blur are not default modernity.

Use image art direction/crops for actual formats, reserving dimensions. Critical content must survive narrow/short screens and zoom without sitting behind navigation. Avoid autoplay carousels/countdowns, invented urgency/discounts and another fixed chrome layer. Missing banner/dismissal capability follows the upstream-gap rule, not a new primitive.

Verify actual responsive placements, contrast on the real image/gradient, destination, focus and combined header/banner height. Exports, when requested, additionally need inspected exact pixel dimensions, crop, sharpness, file weight and truthful preview; do not claim an image was exported when only HTML exists. Web implementation and export are different deliverables.
