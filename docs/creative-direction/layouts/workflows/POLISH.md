# Refine the details after structure and behavior work

Read for a final visual pass or a specific detail defect. Fix unreadable content, broken actions and hierarchy first. Keep the established visual world and package components; polish is not permission for a new stack or another redesign.

- **Nested edges:** where surfaces share an even visible inset, coordinate inner/outer radii with the inset and border. Inspect the silhouette rather than applying a formula across asymmetric or widely separated surfaces. No universal pill radius.
- **Depth:** shadows express elevation, borders structure/state. Use a restrained layered shadow when useful, retaining boundaries/focus in forced colors where shadows may vanish. Don't remove functional input borders or add shadows to every card.
- **Media edge:** a thin neutral inset edge may separate a photo from its surface when necessary. Skip transparent artwork/logos and intentional full-bleed scenes; don't outline every image or impose fixed black/white values outside semantic roles.
- **Optics:** choose UiIcon family/variant/size with visual weight matching adjacent text. Check asymmetric symbols and label boxes at actual scale; prefer an appropriate existing icon and supported spacing to manual SVG surgery, per-label offsets or fixed two-pixel corrections. UiIcon's mask cannot be given an invented stroke prop. Mirror only genuinely directional semantics for RTL, never logos or every arrow.
- **Icon/title rows:** compare the icon with the first text line, not only the outer heading box. Inspect inherited heading padding, margins and leading; this layer's base stylesheet supplies heading block padding. Where the site's composition owns spacing, declare its heading padding/margins deliberately under the site root and let the row align normally. Do not compensate with negative offsets, nth-child shifts, transforms or edits to shared components. Recheck all repeated rows, responsive states and themes after correcting the spacing owner.
- **Hit regions:** keep the visible action and actual hit target coherent, with no overlapping enlarged targets or dead gap between checkbox and label. Decorative layers must not intercept clicks. Use existing primitives, not a new hit-area engine.
- **Theme/state:** inspect actual role colors, opacity composites, focus and disabled/pending boundaries. A border token is not a text token just because its color happens to fit. Dark mode is not merely the reversed light ramp; retain contrast, comfortable chroma and replaceable palette roles. No forced color-space migration or color dependency.

Walk hover/focus/press/pending/error and long/empty states. For motion inspect start/middle/end slowly, then ordinary speed and interruption. Apply MOTION guidance only where motion is in scope; no compulsory press scale, blur crossfade, stagger or animation on repeated tasks.

Trace each problem to its actual owner/token/variant and rendered consumer; similar names in unrelated routes are not evidence. Consolidate one root cause rather than padding a report with symptoms. Separate observed defect, stylistic choice and unverified hypothesis. Fix authorized findings, reinspect and report only meaningful evidence/gaps; no mandatory audit service, score, agent handoff or approval ritual.
